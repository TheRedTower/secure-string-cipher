# Documentation archive

This directory preserves dated plans, audits, and acceptance records that are
useful as engineering history but are no longer operational guidance.

Archived documents deliberately retain their original commands, counts,
version references, and present-tense wording. Read each document against its
stated date and commit. For current project behaviour, start with the
[documentation index](../README.md), [security policy](../../.github/SECURITY.md),
[developer guide](../../DEVELOPER.md), and [release guide](../../RELEASE.md).
